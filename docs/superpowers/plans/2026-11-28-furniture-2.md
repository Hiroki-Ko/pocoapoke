# 家具さがし 改善 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 種類のバッジと絞り込み、日本語名のブラウザ入力＋コピー、「ポケモンから」の選択部分の改善。
**Architecture:** 純粋関数は `src/lib/furniture.ts` に足して vitest でテスト。localStorage の読み書きは `src/lib/localNames.ts` にまとめ、画面は Furniture / FurnitureCard / PokemonPicker を直し、名前入力は新しい `NameSheet`。
**Tech Stack:** 既存（React 19, Tailwind v4, vitest）
**Spec:** `docs/superpowers/specs/2026-11-28-furniture-2-design.md`

## Global Constraints
- D1・API は変えない。push はユーザー
- 種類の表示名は spec の対応表どおり。名前はかな・カナのみ（漢字 U+4E00–9FFF・々 を含むと保存不可）
- localStorage は try/catch で包む（使えなくても画面は動く）

## Review Focus
1. localStorage が壊れた JSON・使えない環境でも落ちない（入力は無いものとして扱う）
2. 入力した名前の前後の空白は削る。空なら削除扱い
3. 正式な日本語名がある家具には入力名を当てない
4. 種類「そのほか」は tag が空文字の家具
5. 選択 0 匹のときはたたんだバーを出さない

### Task 1: ロジック（種類・入力名）
**Files:** Modify `src/lib/furniture.ts`, `src/lib/furniture.test.ts`, `src/types.ts`; Create `src/lib/localNames.ts`, `src/lib/localNames.test.ts`
**Produces:**
- `TAG_LABEL: Record<string, string>`（"" → そのほか）、`tagLabel(tag: string): string`
- `filterFurniture(items, { query, code, tag })` — `tag: string | null` を追加（null は全種類）
- `hasKanji(s: string): boolean`
- `applyLocalNames(items: FurnitureItem[], names: Record<string, string>): FurnitureItem[]` — noJa の家具だけ name を置き換え `noJa: false, localName: true`、並びは日本語名順に並べ直す
- `FurnitureItem` に `localName?: boolean`
- `localNames.ts`: `loadNames(): Record<string,string>`、`saveName(slug, name): Record<string,string>`（trim、空なら削除、漢字なら throw しない＝呼ぶ側で hasKanji を確認）、`exportNames(names): string`（`slug=名前` を slug 順に改行区切り）
- [ ] テスト（RED）: tagLabel の対応 6 件／filterFurniture tag 指定・"" でそのほか／hasKanji／applyLocalNames（noJa のみ置換・正式名は無視・並び直し）／loadNames が壊れた JSON で {}／saveName の trim・空で削除／exportNames の書式
- [ ] 実装 → `npx vitest run` PASS → コミット
