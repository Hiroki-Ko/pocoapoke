# 家具さがし 改善（種類・名前の入力・ポケモン選択） 設計書（短）

- 日付: 2026-11-28 / 規模: 小さな変更 / 前提: `2026-11-26-furniture-design.md`

## 目的
- 家具の種類（おもちゃ・かざりつけ など）をひと目でわかるようにし、種類で絞り込みたい
- 日本語名がない家具の名前を、英語名を書かずにアプリから入力して Claude に渡したい（DB は増やさない）
- 「ポケモンから」の街・ポケモン選択を使いやすくしたい

## 作り方の候補と決定（名前の登録）
| 案 | 内容 | 判断 |
|---|---|---|
| A | D1 に家具の名前テーブルを追加 | 登録のためだけに DB を増やすのは無駄（ユーザー） |
| B | ブラウザにだけ保存 | 端末限定・消える |
| **C（採用）** | ブラウザに一時保存＋「入力した名前をコピー」で Claude に貼って送り、`overrides.json` で正式に反映 | 英語名を書かずに済み、DB も不要 |
| D | 図鑑のスクショで対応づけ | 1 件ごとにスクショが要る可能性 |

## 決まったこと
- 種類の表示名: decoration=かざりつけ、toy=おもちゃ、relaxation=きゅうけい、food=たべもの、road=どうろ、分類なし=そのほか（ユーザー確認済み）
- カードの名前の横に種類のバッジ。「種類 ▾」で 1 つ選んで絞り込み（家具から・ポケモンからの両方）
- 名前の入力: 日本語名がない家具（と、入力済みの家具）のカードの名前をタップ→入力パネル。漢字が入っていたら保存できない。保存先は localStorage `pocoapoke.furniture.names`（`{ slug: 名前 }`）。入力済みは日本語名として扱い上の一覧に出し「入力済み」の印。別枠の見出しに「入力した名前をコピー」（`slug=名前` を 1 行ずつ）
- 正式な日本語名ができた家具（noJa でなくなったもの）の入力は無視する
- 「ポケモンから」の街は、この画面で前回選んだ街（localStorage `pocoapoke.furniture.town`）。初回は住みごこち画面の街
- 街は下線のタブ、ポケモンは丸いチップで見た目を分ける
- 選択部分はスクロールで見えなくなったら、選んだポケモンのアイコン＋「すべて外す」＋「▾」の 1 行を上に固定。タップで選択部分まで戻る
